8 open-source businesses you can run on a few hours a week

Each one ships a free open-source version that markets itself, and a paid version that is either a license key or a small, boring hosted service. Picked from 24 ideas, narrowed to 18 for a closer look.

What the research says

  • Donations don't pay rent.A popular dev tool (mise) reports about $500/month from GitHub Sponsors.
  • Sell convenience, keep code open.Plausible and Ghost earn nearly all revenue from hosting.
  • License keys mean no servers.Sidekiq's free core + paid Pro is run by one person.
  • Regulation creates buyers.GDPR and EU e-invoicing laws turn "nice to have" into "must buy".
